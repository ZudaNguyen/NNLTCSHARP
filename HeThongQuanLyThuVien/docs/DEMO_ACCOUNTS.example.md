# Tài khoản demo (mẫu, không chứa thông tin đăng nhập)

Chỉ điền sau khi đã tạo trên database demo và đăng nhập thành công. Không ghi mật khẩu thật trong file được theo dõi bởi Git.

| Vai trò | Tên đăng nhập | Mật khẩu được lưu tại | Trạng thái kiểm chứng | Ngày kiểm chứng |
|---|---|---|---|---|
| Admin | Chưa xác minh | User Secrets / kho mật khẩu nội bộ | Chưa xác minh | — |
| Thủ thư | Chưa xác minh | User Secrets / kho mật khẩu nội bộ | Chưa xác minh | — |
| Độc giả | Chưa xác minh | User Secrets / kho mật khẩu nội bộ | Chưa xác minh | — |

Tạo bản sao cục bộ tên `DEMO_ACCOUNTS.local.md` trong thư mục này nếu cần ghi tên đăng nhập và vị trí lưu mật khẩu. File local được gitignore. Không chép mật khẩu vào README, issue, source code hoặc log.
